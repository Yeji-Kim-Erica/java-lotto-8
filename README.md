# java-lotto-precourse
우아한테크코스 웹 백엔드 프리코스 3주차 과제: 로또

---

## 📝 구현 기능 목록

### 1. 로또 구매
- [x] **구입 비용 입금**
    - 입력 안내 문구 출력 (형식: `구입금액을 입력해 주세요.`)
    - 구입 금액 입력
        - 로또 1장의 가격: 1,000원
    - **(예외 처리)** 구입 금액 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] {에러메시지 내용}`)
        - 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
        - 숫자로 변환이 불가한 경우: 숫자가 아닌 문자 포함
        - 최소 입금 금액(로또 1장의 가격)보다 적은 경우
        - 로또 가격으로 나누어 떨어지지 않는 경우
        - 최대 입금 가능 금액을 초과한 경우 (최대 입금 가능 금액: 2,147,483,000원)
    - 예외 발생 시, 구입 비용 입금 프로세스 다시 시작
    - 입금 금액 저장
- [x] **로또 발행**
    - 발행할 로또 개수 확인
        - 입금 받은 금액 ÷ 1장당 가격
    - 확인한 개수대로 로또 발행
        - 1장당 6개의 로또 번호 발급 (1~45 범위, 서로 중복되지 않음)
    - 로또 발행 내역 저장
        - 로또 번호 오름차순 정렬
- [x] **로또 발행 내역 출력**
    - 발행한 로또 수량 출력 (형식: `{로또 수량}개를 구매했습니다.`)
    - 각 로또의 번호 출력 (형식: `[{6개의 로또 번호(각 번호는 쉼표로 구분)}]`)

### 2. 당첨 처리
- [x] **당첨 번호 선정**
    - 입력 안내 문구 출력 (형식: `당첨 번호를 입력해 주세요.`)
    - 당첨 번호 입력
        - 6개의 당첨 번호 지정 (1~45 범위, 서로 중복되지 않음)
    - **(예외 처리)** 당첨 번호 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] {에러메시지 내용}`)
        - 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
        - 당첨 번호 개수가 6개가 아닌 경우
        - 숫자로 변환이 불가한 경우: 숫자가 아닌 문자 포함
        - 당첨 번호가 1~45 범위를 벗어나는 경우
        - 당첨 번호가 중복되는 경우
    - 예외 발생 시, 당첨 번호 선정 프로세스 다시 시작
    - 당첨 번호 저장
- [ ] **보너스 번호 선정**
    - 입력 안내 문구 출력 (형식: `보너스 번호를 입력해 주세요.`)
    - 보너스 번호 입력
        - 1개의 보너스 번호 지정 (1~45 범위, 당첨 번호와 중복되지 않음)
    - **(예외 처리)** 보너스 번호 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] {에러메시지 내용}`)
        - 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
        - 숫자로 변환이 불가한 경우: 숫자가 아닌 문자 포함
        - 보너스 번호가 1~45 범위를 벗어나는 경우
        - 보너스 번호가 당첨 번호와 중복되는 경우
    - 예외 발생 시, 보너스 번호 선정 프로세스 다시 시작
    - 보너스 번호 저장
- [ ] **로또 추첨**
    - 일치하는 당첨 번호 개수 확인
    - 일치하는 당첨 번호의 개수가 5개일 경우, 보너스 번호와 일치하는 번호가 있는지 확인 (2등 조건)
    - 등수 확인
      - 1등: 6개 번호 일치
      - 2등: 5개 번호 + 보너스 번호 일치
      - 3등: 5개 번호 일치
      - 4등: 4개 번호 일치 
      - 5등: 3개 번호 일치
    - 발행한 로또 수량만큼 과정 반복
    - 로또 당첨 내역 저장

### 3. 당첨 결과 출력
- [ ] **당첨 내역 출력**
    - 당첨 결과 안내 문구 출력
        - 첫번째 줄 (형식: `당첨 통계`)
        - 두번째 줄 (형식: `---`)
    - 각 등수별 당첨 내역 출력 (일치 개수 기준 오름차순)
      - 5등 (형식: `3개 일치 (5,000원) - {당첨 로또 수량}개`)
      - 4등 (형식: `4개 일치 (50,000원) - {당첨 로또 수량}개`)
      - 3등 (형식: `5개 일치 (1,500,000원) - {당첨 로또 수량}개`)
      - 2등 (형식: `5개 일치, 보너스 볼 일치 (30,000,000원) - {당첨 로또 수량}개`)
      - 1등 (형식: `6개 일치 (2,000,000,000원) - {당첨 로또 수량}개`)
- [ ] **수익률 출력**
    - 로또 당첨 금액 합산
    - 수익률 계산
        - (총 당첨 금액 ÷ 구입 비용) × 100
        - 소수점 둘째 자리에서 반올림
    - 수익률 출력 (형식: `총 수익률은 {수익률}%입니다.`)
